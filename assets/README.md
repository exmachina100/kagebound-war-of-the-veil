# KAGEBOUND Clan / Character VFX Concept Pack v01

This package contains the later-generated character/class VFX concept sheets in the established KAGEBOUND style.

## Files
- `KGB_VFX_Shinobi_ConceptSheet_v01.png` — Shinobi VFX concept sheet
- `KGB_VFX_Ronin_ConceptSheet_v01.png` — Ronin moonlit VFX concept sheet
- `KGB_VFX_Onmyoji_ConceptSheet_v01.png` — Onmyoji veil arts concept sheet
- `KGB_VFX_OniDisciple_ConceptSheet_v01.png` — Oni Disciple VFX concept showcase

## Recommended GitHub folder
Add these into:
`assets/concept-sheets/clan-vfx-v01/`

## Suggested usage
Use these as concept-sheet references for future VFX production, gameplay ability look-dev, sprite/flipbook extraction, and low-poly VFX geometry direction.

These are concept images, not transparent game-ready VFX assets.
